셀러 CS 응대 문구 생성기

배송·환불·클레임 등 반복 CS 문의에 대한 유형·상황·톤별 한국어 답변 초안 생성.

온라인 셀러·1인 운영자는 배송·환불·클레임 같은 반복 CS 문의에 매일 답변 문구를 새로 고민하며 시간을 쓰고, 잘못 답하면 별점 폭탄으로 이어질까 불안해한다. 이 도구는 문의 유형·상황·톤별로 한국어 답변 초안을 만들어 준다.

CS 응대 문구셀러 고객응대배송지연 안내환불 응대클레임 응대스마트스토어 CS
이 도구는 명령줄(CLI) 도구입니다. 아래는 실제 실행 예시 출력입니다. node src/cli.js shipping_delay --reason 주문이 몰려 물류 처리가 지연되고 --eta 이번 주 목요일 로 직접 실행할 수 있습니다.

실행 예시 출력

[배송 지연 안내] · 톤: formal

── 초안 1 ──
안녕하세요, 고객님. 먼저 상품 배송이 예정보다 늦어져 불편을 드린 점 사과드립니다. 확인해 보니 주문이 몰려 물류 처리가 지연되고 있어 배송이 지연되고 있습니다. 이번 주 목요일까지는 받아보실 수 있도록 하겠습니다. 배송 현황은 계속 확인하여, 출고되는 대로 다시 안내드리겠습니다. 감사합니다.
