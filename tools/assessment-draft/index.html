평가문항 출제 골격 생성기

문항 유형별 골격 + 이원목적분류표 + 정답표 + 서술형 채점기준 + 배점 합계 검증.

강사·교육 담당자가 시험문제/평가문항을 매번 처음부터 반복 출제하는 부담을 줄인다. 문항 내용·정답은 지어내지 않고, 출제의 반복 구조(이원목적분류표·정답표·채점기준·배점 검증)를 자동으로 짜준다.

평가문항 출제시험문제 작성이원목적분류표채점기준문항 배점교안 평가
이 도구는 명령줄(CLI) 도구입니다. 아래는 실제 실행 예시 출력입니다. node src/cli.js --demo 로 직접 실행할 수 있습니다.

실행 예시 출력

## 출제 전 검토 체크리스트

- [ ] 모든 문항이 학습목표에 연결되었는가(이원목적분류표)
- [ ] 배점 합계가 목표 총점과 일치하는가
- [ ] 정답표의 정답이 모든 문항에 대해 작성되었는가
- [ ] 서술형 부분점수 기준이 채점자 간 편차 없이 명확한가
- [ ] 객관식에 복수정답·정답 없음·보기 중복이 없는가
- [ ] 난이도 분포가 의도(상/중/하 비율)와 맞는가
- [ ] 특정 학생·집단에 불리하거나 편향된 표현이 없는가
- [ ] 지문·보기의 오탈자와 출처(저작권)를 확인했는가
