정부지원 사업계획서 자가검증 린터

예비/초기창업패키지 제출 전 형식·완결성·예산 산술 정합성을 확정적으로 자가검증.

예비창업패키지·초기창업패키지·청년창업사관학교 등 정부지원 사업계획서를 제출하기 전에, 사용자가 직접 쓴 초안의 형식·완결성·예산 산술 정합성을 확정적으로 자가검증하는 오프라인 도구.

예비창업패키지초기창업패키지사업계획서 검증정부지원 사업계획서청년창업사관학교사업계획서 예산
정직성 경계
  • 이 도구는 사용자가 직접 쓴 초안을 '검증'만 합니다. 내용을 생성·대필하지 않습니다.
  • 합격 가능성·설득력은 판단하지 않습니다. 형식·완결성·예산 산술 정합성만 검증합니다.
이 도구는 명령줄(CLI) 도구입니다. 아래는 실제 실행 예시 출력입니다. node src/cli.js --demo 로 직접 실행할 수 있습니다.

실행 예시 출력

# 정부지원 사업계획서 자가검증 리포트 (데모)
> 대상 공고: 예비창업패키지(예시)
> 작성자: 예비창업자

❌ **제출 전 반드시 고쳐야 할 결함(killer)이 있습니다.** (필수 섹션 누락/빈칸 또는 예산 불일치)

> 이 도구는 제출 형식·완결성·예산 산술 정합성만 검증합니다. 합격 가능성·설득력·시장분석 품질·사업 타당성은 검증하지 않습니다(심사위원 주관 영역).

## 1. 필수 섹션 완결성 (killer)
| 필수 섹션 | 상태 | 비고 |
|------|:----:|------|
| 문제인식 (Problem) | ✅ 작성됨 | 입력: 문제인식 |
| 실현가능성 (Solution) | ✅ 작성됨 | 입력: 실현가능성 |
| 성장전략 (Scale-up) | ❌ 빈칸 | 섹션이 비어 있습니다. 빈칸 없이 채워야 합니다. |
| 팀구성 (Team) | ✅ 작성됨 | 입력: 팀구성 |

_출처: K-Startup 표준 사업계획서 PSST 평가체계(문제인식·실현가능성·성장전략·팀구성). 특정 공고 기준이며 공고마다 항목명·구성이 다를 수 있습니다 — 반드시 해당 공고문을 확인하세요._

## 2. 예산 산술 정합성 (killer)
| 항목 | 금액 |
|------|---:|
| 총사업비 | 100,000,000 |
| 정부지원금 | 75,000,000 (75%) |
| 자부담 현금 | 15,000,000 |
| 자부담 현물 | 0 |
| 자부담 합계 | 15,000,000 (15%) |
| 구성 합계(정부지원금+자부담) | 90,000,000 |

❌ 불일치: 구성 합계가 총사업비보다 **10,000,000 부족**합니다. (총사업비 100,000,000 vs 구성 합계 90,000,000)
- ⚠️ 자부담 비율 15%가 입력한 하한 20%에 미달합니다. 공고 요건을 확인하세요.

_숫자는 전부 입력값이며, 우리는 산술 검증만 합니다. 비율 적정성은 공고 요건으로 확인하세요._

## 3. 정량 목표·산출근거 존재 여부
_존재/형식만 확인합니다. 값의 타당성·설득력은 판단하지 않습니다(심사위원 주관 영역)._

- 매출 산출식(단가×수량×전환율 형태): ⚠️ 미감지
- 시장규모 TAM: ✅ · SAM: ✅ · SOM: ⚠️ 누락
- 고용 정량목표(N명): ⚠️ 미감지
- 매출 정량목표(N원/억): ⚠️ 미감지
- ⚠️ 매출 산출식(예: 객단가 × 수량 × 전환율) 형태가 감지되지 않았습니다. 수익모델의 산출 근거를 숫자로 제시했는지 확인하세요(값의 타당성은 판단하지 않습니다).
- ⚠️ 시장규모에서 SOM(수익시장/수주가능시장)이 감지되지 않았습니다. TAM/SAM/SOM 3계층을 모두 제시했는지 확인하세요.
- ⚠️ 고용 정량목표 숫자(예: 고용 N명)가 감지되지 않았습니다. 정량 목표를 숫자로 기재했는지 확인하세요.
- ⚠️ 매출 정량목표 숫자(예: 연매출 N원/억)가 감지되지 않았습니다. 정량 목표를 숫자로 기재했는지 확인하세요.

## 4. 분량 검증
- 본문 길이: **65자**
- 상한: 7500자 (페이지 환산, 1500자/페이지 추정)
- ✅ 입력한 분량 기준 범위 안입니다.
_분량 기준은 사용자가 입력한 값이며, 페이지 환산은 추정치입니다. 공고문 기준을 확인하세요._

---
_이 도구는 내용을 생성·대필하지 않습니다. 모든 숫자·텍스트는 사용자가 입력한 값 그대로이며, 없는 값을 지어내지 않습니다._
_필수 항목·비율 기준은 특정 연도/공고 기준이며 공고마다 다릅니다. 반드시 지원하려는 공고문을 확인하세요._
