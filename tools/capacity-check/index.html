주간 업무량 현실성 검증기

가용 시간 대비 실질 필요 공수(오버헤드 포함)로 '이번 주 물리적 가능 여부'를 판정하고 협의 문장 초안 생성.

'이번 주, 이거 물리적으로 가능한가?'를 숫자로 답하는 오프라인 도구. 1인·주니어 마케터가 3~4명 몫의 일을 혼자 떠안는 상황에서, 가용 시간 대비 실질 필요 공수를 검증하고 초과 시 쳐낼 업무와 협의 문장 초안을 만든다.

업무량 관리주간 업무 계획공수 산정번아웃 방지업무 우선순위마케터 업무량
이 도구는 명령줄(CLI) 도구입니다. 아래는 실제 실행 예시 출력입니다. node src/cli.js --demo 로 직접 실행할 수 있습니다.

실행 예시 출력

# 3월 2주차 업무량 점검
> 가용 시간 32시간 · 담당: 1인 마케터 · 기간: 3/11~3/15

## 결론
❌ 이번 주 물리적으로 불가능 — 실질 필요 48시간 / 가용 32시간 = 16시간 초과 (사용률 150%)

## 요청 업무 (6건)
| # | 업무 | 공수 | 중요도 |
|---|------|-----:|:------:|
| 1 | 주간 성과리포트 | 6시간 | 상 |
| 2 | 인스타 콘텐츠 5건 제작 | 10시간 | 중 |
| 3 | 신제품 랜딩 카피 | 4시간 | 상 |
| 4 | 월간 뉴스레터 | 5시간 | 하 |
| 5 | 광고 소재 A/B | 8시간 | 중 |
| 6 | 블로그 원고 2건 | 7시간 | 하 |
| | **합계(순수)** | **40시간** | |

## 용량 검증
| 항목 | 값 |
|------|---:|
| 순수 요청 공수 | 40시간 |
| 오버헤드(회의·소통·전환) | +20% |
| **실질 필요 시간** | **48시간** |
| 가용 시간 | 32시간 |
| 사용률 | 150% |
| 초과 | 16시간 |

## 이번 주에서 뺄 업무 (쳐낼 것)
중요도 낮은 순 → 공수 큰 순으로, 가용 시간에 맞을 때까지 지목했습니다.

1. 블로그 원고 2건 — 7시간 (하)
2. 월간 뉴스레터 — 5시간 (하)
3. 인스타 콘텐츠 5건 제작 — 10시간 (중)

→ 위 3건(공수 22시간)을 다음 주로 이관하면 나머지가 가용 시간에 들어갑니다.

## 상사·클라이언트 협의 문장 초안
```
이번 주 가용 시간은 32시간인데, 요청된 업무는 오버헤드(회의·소통·전환) 20% 포함 실질 48시간가 필요합니다. 16시간(가용의 50%p) 초과라, 전부 이번 주에 끝내는 것은 물리적으로 불가능합니다. 우선순위상 [블로그 원고 2건, 월간 뉴스레터, 인스타 콘텐츠 5건 제작]을(를) 다음 주로 이관하거나 마감을 조정하면 나머지는 이번 주에 소화할 수 있습니다. 어느 쪽으로 진행할지 회신 부탁드립니다.
```

---
_이 도구는 '정리'가 아니라 '이번 주에 물리적으로 가능한가'를 숫자로 검증합니다._
_업무 이름·수치는 입력값 그대로이며 지어내지 않습니다. 근거: 고객 발언 CSV 행 19·22(1인 마케터 과부하·야근)._
